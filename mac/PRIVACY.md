# AI SubGauge 隐私与发布范围

## 仓库内容

只纳入源代码、虚构数据测试、应用图标、构建脚本和说明文档。以下内容不上传：

- 个人密钥、密码、Cookie、访问令牌、刷新令牌和实际登录文件。
- 私人 API 地址、内网主机、个人邮箱、家庭地址及本机用户目录。
- 真实账号用量、余额、日程、Wi-Fi 名称、系统位置配置、诊断和日志。
- 聊天记录、调研副本、本地构建缓存、开发快照和安装包。

测试中的凭据、账号标识和恶意 URL 均为虚构样例。第三方开源许可证中的作者署名和功能必需的官方公共服务地址予以保留。

## 应用运行时

- 账户连接由用户在官方客户端或网页中完成；认证数据由对应客户端或独立网页会话管理。
- 凭据仅在需要的本机读取或官方请求过程中使用，不写入本仓库或诊断。
- 用量读取不创建模型对话，不提交提示词。
- 日历和 Wi-Fi 信息只供本机功能使用；天气请求使用用户填写的城市坐标。
- 导出诊断先显示脱敏预览，确认后才复制或保存；仅包含版本、系统版本及固定 provider 状态，不包含账户和凭据。
- 应用的私有设置、诊断和位置备份目录使用 0700 权限，文件使用 0600 权限；导出设置文件同样使用 0600，不改变用户所选文件夹的权限。
- 位置访问诊断中的错误说明会把当前家目录替换为 `~`，但诊断仍可能包含其他本机信息。
- Codex 与 Grok CLI 子进程只接收运行所需的环境变量及必要的本机凭据目录设置；Grok 登录和续期均关闭遥测并剥离其他服务的密钥。
- Claude OAuth 查询使用临时网络会话，禁用 Cookie、缓存与凭据存储，阻止重定向并校验响应地址。读取本机凭据时拒绝符号链接、非普通文件、其他用户所有或组/其他用户可读或可写的文件，以及大于 1 MiB 的文件。

## 后续提交

`.gitignore` 只防止常见文件被误加入，无法识别所有秘密。每次提交前仍应检查暂存文件和新增内容；不要强制加入认证文件、日志或构建产物。

## API 连接

API 密钥由使用者在“添加账户”中自行输入，验证官方只读额度接口成功后才保存在本机系统钥匙串。xAI 的团队 ID 与管理密钥一并存入钥匙串。密钥不写入设置文件、导出、诊断、README 或 Git 提交；新增测试只使用虚构凭据。

查询只发送给界面明确选择的厂商及地区，固定 HTTPS 地址、禁止重定向，不发送模型提示词。HTTP 错误只显示经过筛选的状态说明，不回显服务器原文或密钥。Logo 已随应用离线附带，显示时不访问外部图片服务。移除 API 账户会删除钥匙串项目、取消其刷新并隐藏卡片。

## AI SubGauge 2.0.1

本机登录复用逐家征求同意并分别保存在 UserDefaults；默认不读取 Codex、Claude Code、Grok CLI / Grok Bot 登录。凭据文件对组或其他人可读时拒绝读取，并提示“请将该文件权限改为 600”。Grok 下载、缓存和已安装 CLI 均须通过固定 Developer ID 团队及签名标识校验；失败不执行。

新版本首次启动只复制旧应用数据和本应用旧服务中的 API key，不覆盖已有新数据，不删除旧数据；详见 [迁移方案](docs/MIGRATION.md)。开发预览模式完全离线，只使用演示数据，在初始化迁移、菜单栏和真实凭据读取之前分流。
