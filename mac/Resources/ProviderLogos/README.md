## Use in the app

All PNGs are 128 by 128 pixels, RGBA, with transparent backgrounds. They were downsampled from the original 640 by 640 PNGs without changing brand shapes or colors. No other source image metadata is retained. Root files are for light appearance; matching `dark/` files are for dark appearance. Bundle this directory, including the license, for offline use without a runtime dependency.

| Local file | Upstream light file |
| --- | --- |
| `openai.png` | `light/openai.png` |
